# Cairn design system

Cairn is a relationship workspace for people who return to the same records every day. The overview opens with priorities and the motion of the pipeline, using a single composition with metrics above a stage chart and an upcoming-work column. Working surfaces give space to data through fine dividers, compact row density and a consistent command bar.

The overview’s midnight-blue brief borrows the sign-in screen’s orbital motif. It puts the local date, primary actions and due work in one place. Keep the other working surfaces quiet. Keyboard search separates a compact grid of workspace actions from record results.

- Color: midnight #192333 for primary ink, steel #526276 for secondary, frost #F3F6FA for the navigation rail, white for working surfaces, cobalt #2747DE for actions, and pale blues and violets for status and chart series. Green and amber are reserved for outcomes and deadlines.
- Typography: system UI sans with a heavier display scale. Use 13–15px for working text, tabular figures for metrics, and 32–38px page titles with tight tracking. Avoid decorative labels.
- Structure: 236px desktop rail, 60px breadcrumb bar and 32px content gutters on wide screens. Navigation becomes a compact rail and then a mobile disclosure. Tables and boards scroll locally. A record or Copilot can open without losing the underlying list.
- Components: Lucide line icons, 8px buttons and inputs, 12px surface corners, semantic tables, accessible Radix dialog for forms and drawers, visible focus rings, and a distinct active state. Use labels and keyboard alternatives for chart navigation and stage moves.
- Feedback: show explicit errors in forms, announce saved changes, preserve draft values after a failed write, and use short transitions with a reduced-motion fallback.
- Inspiration: use Linear’s readable density and Attio’s ability to keep record work in one place. The Cairn visual identity comes from its cobalt rail accents and a pipeline overview built from live counts.
